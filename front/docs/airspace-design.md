# 空域态势前端

目标：将现有 Vue2 模板改为可操作的 ADS-B 空情工作台，地图使用 Cesium，通过 Express 接入 dump1090 实时信号。

- 用户选择整体深色的传统监控台风格：深灰蓝顶部导航、左侧面板和详情，深色地图，蓝色常规目标、橙色选中目标；使用清晰的表格、细分隔线，避免大面积渐变和装饰性效果。
- 顶部 64px，底部状态栏 30px；左侧 260px，详情在地图右侧浮出。小屏下收起左侧辅助内容。
- 仅展示后端推送的真实目标，未配置或断线时清空列表。航空器列表支持呼号/ICAO 搜索、状态筛选及地图定位。
- 地图支持目标点选、二维/三维、缩放、复位、航迹、标签和接收范围图层。选中后显示数据详情，可跟随目标。
- 数据适配器统一 dump1090-fa/readsb 与旧版 dump1090 字段，保留原始单位；缺少位置、过期位置不绘制，未知值显示占位。
- 数据接入面板填写 dump1090 主机和 TCP 端口 30002，配置保存至 MariaDB。后端解码 AVR 报文，每秒通过 WebSocket 推送快照；错误和离线显式呈现。页面卸载时停止订阅与定时器。
- 不假定 ADS-B 自带机型、注册号、航线和运营商数据，无这些字段时不编造。

实施顺序：数据适配及边界测试 → Cesium 静态资源与地图组件 → 布局/列表/详情/接入面板 → 构建、检查、浏览器交互验证。

底图支持 Esri 卫星影像、Google 官方卫星影像、CARTO 深色地图及低精度离线图层，地址由前端环境配置提供。Cesium 本体随应用打包；仅在真实站点坐标已配置时显示参考距离圈，不代表实测接收范围。
