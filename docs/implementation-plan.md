# 第一阶段实施计划

后续 TCP 解码、数据库配置持久化与 WebSocket 推送见 [ADS-B 接入计划](superpowers/plans/2026-09-27-adsb-tcp.md)，当前架构以 [架构说明](architecture.md) 为准。

1. 后端：独立 Express 应用和入口，公共响应/错误/配置/数据库池，模块注册，ADS-B 快照代理和只读资料查询。使用 `.env` 连接用户提供的 MariaDB `radio_station`，表名与实际字段待导入后配置。
2. 地图：独立加载器、底图注册和图层管理，Esri / Google / CARTO / 本地底图，切换竞态和失败恢复测试。
3. 界面：紧凑暗色布局，取消装饰性标题，加入五类信号模块入口，保留飞机点选、详情与跟随。
4. 集成：公共前端 HTTP/轮询方法，统一后端响应解析，模块状态检查；Vue 开发服务代理 `/api/v1` 到 Express。
5. 验证：前端 lint / 全套单元测试 / 生产构建；后端配置、数据库查询参数、源异常、API、Google会话生命周期测试；真实 HTTP 启动检查。数据库名和表未提供时只报告待配置，不声称连接或导入成功。
